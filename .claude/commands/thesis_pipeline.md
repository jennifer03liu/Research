# 論文大內總管 (Thesis Pipeline)

當您想要處理新章節的論文，或需要將新的 Markdown 內容轉換為最終的 Word 排版文件時，請呼叫此 Workflow。

## 執行流程

1. **AI 學術潤稿 (手動/自動執行)**:
   - 由 AI 先針對您提供的論文文字進行「極度嚴格潤稿」。
   - **規則**:
     1. 移除不必要的引號（保留學術變數本身即可）。
     2. 首次出現的重要術語標示：「中文（原文，簡寫）」。後續皆使用中文。
     3. 修飾文法、刪除贅字、保持 APA 7th 客觀語氣。
   - 將修改後的內容儲存至一個如 `ChX_XXX_修訂版.md` 的檔案中。

2. **自動整合引用與排版**:
   - 執行核心的統一腳本 `thesis_formatter.py`。
   - 該腳本將自動執行以下三步驟：
     - 將 Markdown 中的 APA 引用與 CSV 文獻庫進行模糊比對，轉換為 `{作者, 年份 #RecordNumber}` 格式。
     - 匯出不匹配的漏網明細。
     - 自動產出排版好（包含標楷體標題、縮排、行距）的 `.docx` 檔案。

// turbo-all
3. 執行指令 (替換掛號中的檔案名稱)：
```bash
python ".agent\skills\thesis-pipeline\scripts\thesis_formatter.py" "04_論文撰寫與產出\論文\[您要處理的檔名.md]"
```

4. **最終檢查**:
   - 通知使用者檢查產出的 Word 檔案，並確認終端機顯示的「未匹配清單」中是否需要進一步補全文獻庫。
